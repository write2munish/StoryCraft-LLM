# 📦 Data Pipeline: TinyStories

This directory manages the datasets used throughout the **StoryCraft-LLM** course.

---

## 📖 The TinyStories Dataset
Pioneered by Microsoft Research (*Eldan & Li, 2023*), TinyStories is a synthetic dataset generated by GPT-3.5 and GPT-4 containing short stories using a simple vocabulary suitable for 3–4 year old children.

### Why TinyStories?
1. **Manageable vocabulary:** Around 3,000–4,000 unique word roots, enabling compact tokenizers.
2. **Grammatical purity:** Contains diverse English sentence structures (active/passive, questions, dialogues, past/present/future tenses) without internet noise or toxic scraping artifacts.
3. **Low parameter requirement:** An 8.5M parameter model achieves high fluency and coherence on this data in under 45 minutes on a laptop.

---

## 🚀 Quick Download

To download a local training slice (100,000 stories) run:

```bash
python download_tinystories.py --num_samples 100000 --output_dir ./raw
```

This creates:
- `data/raw/tinystories_train.txt`
- `data/raw/tinystories_valid.txt`
